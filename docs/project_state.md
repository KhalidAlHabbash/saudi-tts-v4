- **Expected training approach:** full fine-tuning of the SILMA/F5 acoustic CFM/DiT from pinned EMA weights with fixed pretrained Vocos. The Mac profile is FP32, batch 1, accumulation 8, <=8-second clips, activation checkpointing, zero workers, and MPS-first. The RunPod Secure RTX PRO 4500 Blackwell profile is single-GPU CUDA BF16, batch 2, accumulation 4, frames threshold 1,500, four workers, pinned memory, and TF32-enabled FP32 matmuls. Both retain an effective batch of eight and the same 120,000-update optimizer schedule; ordinary AdamW remains unfused and no GradScaler or `torch.compile` is used.
- **Python:** CPython 3.11.7 arm64 in the local `.venv`; Python 3.12 in a system-site-packages `.venv-runpod` on official template `runpod-torch-v280` / image `runpod/pytorch:1.0.2-cu1281-torch280-ubuntu2404`.
